# CondoriFlores — Práctica 1 (View Binding)

App Android simple: ingresa **nombre** y **carrera**, pulsa **Mostrar Datos** y se muestran en `tvResult`.

## IDs de la interfaz

- `etNombre` — EditText nombre  
- `etCarrera` — EditText carrera  
- `btnMostrar` — Button  
- `tvResult` — TextView resultado  

## Cómo usar

1. Abre el proyecto en Android Studio (carpeta raíz).
2. Sync Gradle.
3. Run ▶ en un emulador o dispositivo.

Ver `GUIA_PASO_A_PASO.md` para armar la interfaz en Design con estos IDs.
